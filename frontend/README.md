# 翊想樂園前端

橘黃、奶油色與暖棕色的復古遊樂園風格。所有前端檔案集中於此，不需安裝 npm 套件或編譯。

- `index.html`：首頁、問題表單、牌陣、洗牌、逐張抽牌與結果版面。
- `styles.css`：電腦／手機版面、動畫、減少動態效果與列印樣式。
- `shuffle.css`：手勢洗牌桌樣式。
- `journey.css`：逐步分頁介面、切頁過場與手機版步驟列。
- `app.js`：串接後端 API、輸入驗證、抽牌流程、錯誤與重試、分頁進度恢復。
- `assets/sunlit-park.svg`：自製帳篷、摩天輪、水晶球與旋轉木馬背景插畫。
- `assets/card-back.svg`：自製抽牌牌背。
- `assets/wonder-card.svg`：側邊票券的裝飾牌。
- `assets/ferris-wheel.svg`：品牌摩天輪與網站圖示。

## 開啟方式

在專案根目錄執行 `./scripts/start.ps1`，瀏覽 `http://127.0.0.1:3000/`。FastAPI 在開發環境會一併提供前端與 API，無需跨來源設定。不要直接以檔案方式開啟 HTML，因為互動功能需要後端。

Docker 模式執行 `docker compose up --build -d`，開啟 `http://127.0.0.1:8080/`，由 Caddy 提供前端並轉送 `/api/*`、`/cards/*` 至後端。主機 3000 埠仍可直接檢查後端；可設定 `WEB_PORT` 改變 Caddy 對外埠。

## 行為

採用一次只顯示一個步驟的介面：首頁入口 → 問題頁 → 牌陣頁 → 洗牌頁 → 抽牌頁 → 解讀結果。網址 hash 對應各頁，支援上一頁、瀏覽器返回與重新整理恢復草稿／占卜進度。抽牌後問題與牌陣會鎖定；返回洗牌頁只供回看，不重新洗牌。修改已開始的占卜需明確按「重新開始」。

輸入問題（100 字計數與超限警告）→ 選擇四種牌陣之一 → 建立占卜 → 手勢洗牌 → 逐張點選三張 → 主動要求 AI 解讀 → 顯示摘要、各牌分析、建議與反思問題。比較選項牌陣會額外要求 A、B 內容。

手勢洗牌使用 Pointer Events：手機手指按住移動；電腦按住滑鼠左鍵或觸控板拖移（支援裝置也可用輕點拖移）。牌會隨手勢移動；手勢達基本混合量後可按「洗好了」，不必等待固定動畫時間，也能繼續洗。觸控板雙指捲動不視為洗牌。僅牌桌內設定 `touch-action: none`，桌外仍可捲動頁面。鍵盤使用者可聚焦牌桌後用方向鍵洗牌。離開視窗或手勢中斷會停止拖移，不會卡住。

按「洗好了」時呼叫 `POST /api/readings/{id}/shuffle`，後端重新以安全亂數產生完整牌序與正逆位，成功後才進入選牌。前端裝飾牌的移動不會揭露或控制實際牌面。已開始抽牌後，後端禁止重洗；這個 API 不呼叫模型，也不使用 AI 額度。

真實洗牌與正逆位由後端決定，前端動畫不改變牌序。前端送出原始位置索引與 `drawIndex`，不自動重排剩餘牌。模型呼叫只會在使用者按下「打開指引」後發生，不會因為載入首頁或洗牌觸發。

占卜 ID、存取憑證與洗牌階段保存在 `sessionStorage`，可在同分頁重新整理時恢復；不保存 API 金鑰。錯誤時保留三張牌，可重試。顯示使用者與模型文字時使用 `textContent`，不把內容當 HTML 執行。

「輸出圖片」會在瀏覽器產生完整 PNG 指引，開啟預覽供手機長按儲存，並提供下載；支援檔案分享的瀏覽器另外顯示分享按鈕。「列印／另存 PDF」保留瀏覽器列印功能。裝飾插畫為本專案自製 SVG；真實牌面來源見主專案 README。Google Fonts 無法連線時使用系統替代字型。
